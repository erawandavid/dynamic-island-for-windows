# Decision log

Small decisions that `PLAN.md` doesn't answer, with the reasoning. Newest last. Big or hard-to-reverse decisions are discussed with the owner first.

| # | Date | Phase | Decision | Why |
|---|---|---|---|---|
| 1 | 2026-10-21 | 0 | The repository root is the project root (no `pulau/` subfolder); the GitHub repo is `dynamic-island-for-windows`, the product is still called "Pulau". | The plan's `pulau/` folder is just the clone directory. |
| 2 | 2026-10-21 | 0 | Solution file is `Pulau.slnx` (the XML solution format, default for `dotnet new sln` in .NET 10). | Readable, merge-friendly; supported by the .NET 10 SDK, Visual Studio 2022 17.13+/2026, Rider and C# Dev Kit. |
| 3 | 2026-10-21 | 0 | `Pulau.App` uses `AssemblyName=Pulau` and `RootNamespace=Pulau`. | The shipped executable is `Pulau.exe`, and the `App` class is `Pulau.App` instead of the awkward `Pulau.App.App`. |
| 4 | 2026-10-21 | 0 | `Pulau.App` sets `EnableWindowsTargeting=true`. | The whole solution compiles on Linux/macOS (contributors, cloud agents); the app still only runs on Windows. |
| 5 | 2026-10-21 | 0 | Tests use xUnit v3 (`xunit.v3`) on Microsoft.Testing.Platform, opted in via `"test": { "runner": "Microsoft.Testing.Platform" }` in `global.json`. | Current stable xUnit line; on the .NET 10 SDK `dotnet test` needs the MTP opt-in for it. `Microsoft.NET.Test.Sdk` and `xunit.runner.visualstudio` stay for IDE test explorers that still use VSTest. |
| 6 | 2026-10-21 | 0 | `global.json` pins `10.0.100` with `rollForward: latestFeature`. | Any .NET 10 SDK (10.0.1xx or newer feature band) works; .NET 11 does not get picked silently. |
| 7 | 2026-10-21 | 0 | Default version is `0.1.0-dev` (`VersionPrefix`/`VersionSuffix` in `Directory.Build.props`). | Local builds are clearly marked as dev; release builds pass `-p:Version=` from the git tag (Phase 6). |
| 8 | 2026-10-21 | 0 | Phase 0 app is a placeholder `Views/MainWindow` that says "Pulau is running (empty shell)". | Proves the app starts; it is replaced by `IslandWindow` in Phase 1. |
| 9 | 2026-10-21 | 0 | CI uses `actions/checkout@v5` and `actions/setup-dotnet@v5` with `global-json-file`, read-only `contents` permission, and cancels superseded runs. | Current major versions (Node 24); SDK version comes from one place. |
| 10 | 2026-10-21 | 1 | The host window is a fixed 480 × 220 DIP transparent window placed with `SetWindowPos` in **physical pixels**, from the monitor's work area and effective DPI. The math lives in Core (`IslandPlacement`) and is unit-tested; WPF's `Left`/`Top` are not used. | Under Per-Monitor V2, WPF's DIP coordinates depend on the window's current DPI, which is ambiguous while moving between monitors. If WPF resizes the window on `WM_DPICHANGED`, a follow-up reposition corrects it. |
| 11 | 2026-10-21 | 1 | Click-through relies on WPF's per-pixel-alpha layered window (`AllowsTransparency`): fully transparent pixels don't receive mouse input. The fallbacks from PLAN 3.4 are only built if manual test 1.5 fails. | **Pending verification on Windows.** |
| 12 | 2026-10-21 | 1 | Phase 1 always uses the primary monitor. Choosing a monitor arrives with settings (Phase 5). | Keeps Phase 1 small; `Monitors.Primary()` is the single place to change. |
| 13 | 2026-10-21 | 1 | Unhandled UI-thread exceptions are logged and marked handled (the app keeps running). AppDomain-level unhandled exceptions are logged as Fatal and the log is flushed before the process ends. Unobserved task exceptions are logged and observed. | Nothing fails silently, and a glitch in one UI part doesn't take the island down. |
| 14 | 2026-10-21 | 1 | Tray icon is created with `ForceCreate(false)`, i.e. Efficiency Mode off. Its menu opens on left or right click. | H.NotifyIcon turns Efficiency Mode (EcoQoS) on by default, which would throttle the whole process, animations included. |
| 15 | 2026-10-21 | 1 | A second launch exits immediately and silently (named mutex `Local\Pulau.SingleInstance.<GUID>`). It does not signal the running instance. | Matches PLAN; "bring the island back on second launch" can be added later. |
| 16 | 2026-10-21 | 1 | Logs go to `%LOCALAPPDATA%\Pulau\logs\pulau-YYYYMMDD.log`: daily files, 7 kept, 10 MB cap per file (rolls within a day). Debug builds log at Debug level, Release at Information. | The size cap protects the disk if something logs in a loop. |
| 17 | 2026-10-21 | 1 | `GWL_EXSTYLE` is set with `GetWindowLong`/`SetWindowLong`, not the `Ptr` variants. | CsWin32 doesn't generate `*WindowLongPtr` for AnyCPU builds; extended styles are 32-bit on every architecture. |
| 18 | 2026-10-21 | 1 | `WM_MOUSEACTIVATE` returns `MA_NOACTIVATE` in addition to the `WS_EX_NOACTIVATE` style. | Belt and braces: clicking the island must never take focus. |
| 19 | 2026-10-21 | 1 | The app icon is generated by `tools/make_icon.py` (Pillow): a black pill with a light outline, 2:1 aspect, 16–256 px. | Original, reproducible artwork; the outline keeps it visible on dark taskbars. |
